# 🚀 Resume Intel
> **AI-Powered Resume Analysis & Optimization Engine**

![React](https://img.shields.io/badge/framework-React-cyan)
![Powered By](https://img.shields.io/badge/Powered%20By-Gemini%20AI-orange)

**Resume Intel** is a cutting-edge web application designed to help job seekers bypass Applicant Tracking Systems (ATS) and impress human recruiters. By leveraging Google's **Gemini AI**, it performs a "Dual-Lens" analysis—simulating both a ruthless machine algorithm and a seasoned technical recruiter.

---

## ✨ Features

*   **📄 PDF Resume Parsing**: Instantly extracts text from your uploaded resume.
*   **🤖 Dual-Lens Analysis**:
    *   **ATS Mode**: Checks for keyword stuffing, formatting errors, and machine readability.
    *   **Recruiter Mode**: Evaluates impact, metrics, and tone.
*   **📊 Visual Insights**: Match score gauges and skill gap radar charts.
*   **💡 Actionable Feedback**: Specific advice on what to fix, from missing keywords to passive voice.
*   **🔒 Privacy First**: Your API keys and data are stored locally in your browser.

---

## 🛠️ How to Use

1.  **Upload Resume**: Click the upload area to select your PDF resume.
2.  **Paste Job Description**: Copy the job description (JD) you are applying for into the text box.
3.  **Configure AI**:
    *   Open the Sidebar.
    *   Enter your **Gemini API Key** (see below).
    *   Select your preferred model (e.g., *Gemini 1.5 Flash* for speed or *Pro* for depth).
4.  **Analyze**: Click the **"Start Analysis"** button and watch the magic happen!

---

## 🔑 Getting Your API Key

This application requires a Google Gemini API Key to function. It's free to get started!

1.  Go to the [Google AI Studio](https://aistudio.google.com/app/apikey).
2.  Click **"Create API key"**.
3.  Copy the key (starts with `AIza...`).
4.  Paste it into the **API Key** field in the Resume Intel sidebar.

> **Note**: Your key is encrypted and stored locally on your device. It is never sent to our servers.
